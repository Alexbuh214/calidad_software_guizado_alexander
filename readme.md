## Descripción

Repositorio correspondiente a la materia **Calidad de Software**, donde se almacenarán ejercicios, prácticas y proyectos realizados durante el desarrollo de la asignatura.

En esta materia se estudiarán conceptos relacionados con la calidad de los sistemas de software, las buenas prácticas de desarrollo y diferentes tipos de pruebas para verificar el correcto funcionamiento de las aplicaciones.

## Conceptos básicos

### Calidad de Software

La **calidad de software** se refiere al conjunto de características y prácticas que permiten evaluar si un sistema cumple con los requisitos establecidos, funciona correctamente y puede mantenerse y mejorarse con facilidad.

### Pruebas de Software

Las **pruebas de software** son procesos utilizados para detectar errores y comprobar que una aplicación funciona de acuerdo con lo esperado.

### Pruebas Unitarias

Las **pruebas unitarias** permiten comprobar de manera individual pequeñas partes de una aplicación, como funciones, métodos o componentes.

Su objetivo principal es verificar que cada unidad del código produzca el resultado esperado de forma independiente.

### Pruebas E2E

Las **pruebas End-to-End (E2E)** permiten comprobar el funcionamiento de una aplicación desde el punto de vista del usuario, verificando un flujo completo de principio a fin.

Por ejemplo, en una aplicación web se podría probar el proceso completo de iniciar sesión, ingresar a una sección y realizar una determinada acción.

### Integración Continua

La **integración continua (CI)** consiste en integrar y validar frecuentemente los cambios realizados en un proyecto mediante procesos automatizados, como compilaciones y pruebas.

### Control de Versiones

El **control de versiones** permite registrar y administrar los cambios realizados en el código de un proyecto. Una de las herramientas más utilizadas para este propósito es Git.
